# Open delegated conversations from call cards

DSMM role, category and native subagent cards open the child's conversation through the Host's `uiWorkspace.openSession({parentSessionId, childSessionId, mode})`. The parent is the card's session, not the currently selected conversation. The button leaves the native presenter's own tool inspection and disclosure controls intact.

Resolve the child from a confirmed result or a correlated observation for that call. Use the native subagent catalog to distinguish local sessions from external executions. A reservation, label, job ID or conflicting identity cannot identify a destination. Preserve native `unknown` mode for an identified local history entry. Navigation does not start or resume another delegation.

Exercise the actual button and destination with distinct child IDs and history replay; verify that a card without a confirmed local target cannot navigate. Keep keyboard and pointer activation on the existing native button component.
